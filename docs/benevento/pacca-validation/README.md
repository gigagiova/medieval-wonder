# Pacca burial access verification

Reconstruction of a compact burial room beside the inferred San Pietro precursor,
not a surveyed copy of the2023 excavation. See ../PIAZZA-PACCA.md.

Matched before/after renders use the same camera, production materials and
nearby town chunks under isolated lighting. `interior.png` shows the four
closed cists. The real Player descends, crosses the room and returns to the
street: six waypoints passed, no browser errors. A stone bridge preserves
the adjacent church doorway. The final render closes the wall/floor seam
found during visual review.

These isolated views draw nine unculled chunks and are not phone-budget
measurements. Full-world phone-viewport measurements are recorded separately
in ../missing-sites-world/report.json.

Reproduce with tools/capture-pacca-burials.py and tools/check-pacca-burials.ts.
